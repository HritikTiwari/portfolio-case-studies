# Overview

Enterprise Transaction Management Platform is a production web application developed using **C#, ASP.NET Web Forms, and Microsoft SQL Server** to manage operational workflows, user account balances, billing transactions, and administrative reporting.

The platform supports secure role-based access, financial record management, dashboard analytics, and reliable transactional processing for internal business operations.

## Role-Based Authorization
