# Overview

Facility Access Management Platform is an enterprise web application built using **C#, ASP.NET Web Forms, and Microsoft SQL Server** to streamline visitor registration, logistics entry, security verification, and administrative monitoring.

The platform enables organizations to manage facility access, track check-in/check-out events, and provide secure, role-based administrative operations.
