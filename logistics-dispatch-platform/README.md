# Overview

Logistics & Dispatch Management Platform is a production web application built using **C#, ASP.NET Web Forms, and Microsoft SQL Server** to streamline fleet dispatch operations, logistics tracking, fuel transaction management, and operational reporting.

The platform automates dispatch workflows, generates audit-ready reports, and provides secure administrative tools for managing logistics operations.
